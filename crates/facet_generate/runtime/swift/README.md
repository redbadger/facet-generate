# Serde

The Swift serialization runtime for code generated by `facet_generate`: the `Serializer`
and `Deserializer` protocols, their bincode implementations, and the `Int128`/`UInt128`
and `Indirect` helpers the generated types depend on.

The generator embeds `Sources/Serde` with `include_dir!` and installs it into every
generated Swift package, so a change here ships to users. The Swift package in this
directory exists so the runtime can be tested on its own: `just swift-test` runs it on
macOS and Linux (it is skipped on Windows). Swift 6 tools are required, matching
`Package.swift`.
